positional arguments:
  evidence              evidence JSON path (default: None)

options:
  -h, --help            show this help message and exit
  --json                machine-readable JSON output (default: False)
  --token TOKEN         Straiker PAT (s6r_pat_...) or JWT; else $STRAIKER_PAT (default: None)
  --base BASE           v3 API base URL (default: https://api.prod.straiker.ai/api/v3)
  --bridge-base BRIDGE_BASE
                        Ascend lease-service base URL (where bridges fetch probes and post
                        results) (default: https://ascendai-bridge.prod.straiker.ai)
  --url URL             live page with a chat widget: drive a real browser and capture the true
                        contract (default: None)
  --api URL             an HTTP API endpoint (or just the base URL — the path is discovered). No
                        browser. (default: None)
  --curl FILE           a curl command in a file, or '-' for stdin. Zero guessing. (default: None)
  --spec BASE_URL       find an OpenAPI/Swagger spec under this base URL and build from it
                        (default: None)
  --har HAR             HAR file to classify (default: None)
  --header 'Name: value'
                        raw header (repeatable), honored by all sources, e.g. 'X-Api-Key: …'. A
                        value written env:NAME is read from the environment and never stored in
                        the config (default: None)
  --bearer TOKEN        Authorization: Bearer <token>; env:NAME keeps the token out of the config
                        (default: None)
  --api-key NAME:VALUE[:in=header|query]
                        API key, e.g. 'x-api-key:abc', 'key:abc:in=query', or 'x-api-
                        key:env:MY_KEY' to reference the environment instead of storing the value
                        (default: None)
  --basic USER:PASS     HTTP Basic auth; 'user:env:MY_PW' references the password (default: None)
  --cookie 'k=v; k2=v2'
                        Cookie header for a session-gated target; 'session=env:MY_SESSION'
                        references the value (default: None)
  --token-file PATH     read a bearer token from this file (default: None)
  --body-field key=value
                        extra JSON body field, repeatable — for agents whose key/tenant lives in
                        the BODY, e.g. --body-field apiKey=abc --body-field workspace=support. Use
                        key:=raw for a non-string literal (true/1/{...}). (default: None)
  --login-url URL       POST here first to exchange creds/code for a token (default: None)
  --login-body JSON|FORM
                        body for --login-url. JSON ('{"code":"1234"}') or form-encoded
                        ('grant_type=client_credentials&client_id=…') — OAuth2 is form-encoded.
                        (default: None)
  --token-path DOTPATH  dot-path to the token in the login response (default: token) (default:
                        token)
  --login-method {POST,GET}
                        verb for --login-url (default: POST). GET for a bootstrap page that sets a
                        session cookie or embeds a CSRF token. (default: POST)
  --token-regex RE      extract the token with a regex (first capture group) instead of --token-
                        path — for a token embedded in HTML, e.g. 'csrf-token" content="([^"]+)'
                        (default: None)
  --token-header NAME   send the extracted token in this header verbatim (e.g. X-CSRF-Token)
                        instead of as 'Authorization: Bearer <token>' (default: None)
  --insecure            skip TLS verification (self-signed internal targets) (default: False)
  --ca-bundle PATH      custom CA bundle for TLS verification (default: None)
  --client-cert PATH    client certificate (PEM) for mTLS (default: None)
  --client-key PATH     client private key (PEM) for mTLS (default: None)
  --proxy URL           HTTP(S) proxy for the probe/validate calls (default: None)
  --cdp [ENDPOINT]      with --url: attach to a browser you are ALREADY signed into (start it with
                        `chrome --remote-debugging-port=9222`) instead of launching one. The only
                        route into an Entra / SAML / SSO-gated target. Default endpoint
                        http://127.0.0.1:9222; the written adapter attaches the same way, and your
                        browser is never closed. (default: None)
  --prompt-hint PROMPT_HINT
                        with --curl: the literal prompt text used in that command (default: None)
  --allow-internal      allow link-local/cloud-metadata hosts (169.254/fd00::) — off by default
                        (default: False)
  --timeout TIMEOUT     per-request timeout in seconds (default: 20.0)
  --prompt PROMPT       benign prompt to send during capture (default: Hello, what can you help me
                        with?)
  --headless            run the capture browser headless (faster, but bot protection often blocks
                        it) (default: False)
  --no-headless         force a visible browser (default; most reliable against bot protection)
                        (default: True)
  --manual              open the page and let YOU drive the widget while we record (for widgets
                        our automation cannot reach) (default: False)
  --settle SETTLE       seconds to wait for page/widget/reply (default: 6)
  --response-path DOTPATH
                        where the answer is in the response, e.g. data.reply — set it explicitly
                        when the CLI cannot find it, or to override its guess (scriptable)
                        (default: None)
  --save-evidence SAVE_EVIDENCE
                        also write the raw captured evidence here (default: None)
  --code                advanced: also write the adapter as an editable Python module (the CLI
                        picks the adapter kind automatically; you don't need this normally)
                        (default: False)
  --out OUT             write the drafted config here (default: None)
