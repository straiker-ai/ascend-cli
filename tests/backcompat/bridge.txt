usage: ascend [--json] [--token TOKEN] [--base URL] <command> [<verb>] [flags] bridge
       [-h] [--json] [--token TOKEN] [--base BASE] [--bridge-base BRIDGE_BASE]
       {start,ls,stop,logs,grade,sync} ...

Manage the CLI's built-in bridge for bridge-type apps.

`assess run` starts and stops a bridge for you, so this is
rarely needed. The exception is `bridge ls`: it flags a live
assessment that nothing is answering, and unanswered probes
are not findings — that run finishes looking CLEAN having
measured nothing.

positional arguments:
  {start,ls,stop,logs,grade,sync}
    start               start a detached bridge per app (key comes from the local store)
    ls                  list bridges + flag live assessments with NO bridge
    stop                stop bridges
    logs                show a bridge's log
    grade               grade a run from the relay's own recording: answered or not, and what the
                        replies gave away
    sync                reconcile bridges to assessment state — start for running/paused apps,
                        stop for terminal (the fallback after a Console-side change)

options:
  -h, --help            show this help message and exit
  --json                machine-readable JSON output (default: False)
  --token TOKEN         Straiker PAT (s6r_pat_...) or JWT; else $STRAIKER_PAT (default: None)
  --base BASE           v3 API base URL (default: https://api.prod.straiker.ai/api/v3)
  --bridge-base BRIDGE_BASE
                        Ascend lease-service base URL (where bridges fetch probes and post
                        results) (default: https://ascendai-bridge.prod.straiker.ai)
