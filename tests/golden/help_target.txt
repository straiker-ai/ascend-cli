usage: ascend [--json] [--token TOKEN] [--base URL] <command> [<verb>] [flags] target
       [-h] [--json] [--token TOKEN] [--base BASE] [--bridge-base BRIDGE_BASE]
       {add,inspect,list,show,check,rm,types} ...

positional arguments:
  {add,inspect,list,show,check,rm,types}
    add                 onboard a target from a URL, a cURL/HAR file, a cloud-runtime identifier,
                        or a saved config
    inspect             look at a target first: what it is, what it needs, what is already
                        registered
    list                every target: its adapter, whether it is registered, whether it is serving
    show                everything bound to one target, in one place
    check               re-prove a target against its live endpoint (the hard gate)
    rm                  delete the application and drop its stored key
    types               the kinds of target this can speak to (adapter types)

options:
  -h, --help            show this help message and exit
  --json                machine-readable JSON output (default: False)
  --token TOKEN         Straiker PAT (s6r_pat_...) or JWT; else $STRAIKER_PAT (default: None)
  --base BASE           v3 API base URL (default: https://api.prod.straiker.ai/api/v3)
  --bridge-base BRIDGE_BASE
                        Ascend lease-service base URL (where bridges fetch probes and post
                        results) (default: https://ascendai-bridge.prod.straiker.ai)
